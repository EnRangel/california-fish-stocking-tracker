# Privacy Policy

Effective date: October 23, 2026

California Fish Stocking is an independent, unofficial Firefox extension. The
developer does not collect, receive, sell, or share personal information
through the extension.

## Information stored in Firefox

The extension stores favorite water IDs and a temporary copy of public stocking
records using Firefox extension storage. This information stays in the user's
local Firefox profile and is not sent to the developer.

Removing a favorite removes that ID from the saved favorites. Firefox normally
removes an extension's local storage when the extension is uninstalled.

## Network connections

Opening or refreshing the popup requests public stocking information from the
California Department of Fish and Wildlife schedule and its ArcGIS data
service. The extension omits browser credentials and does not include the
user's search text or favorites in these requests.

Like other internet services, CDFW and ArcGIS may receive ordinary connection
information such as an IP address and browser user agent. The extension
developer does not receive those request logs.

Google Maps is contacted only after the user selects an “Open in Google Maps”
link. The link contains the public coordinates of the selected water body.
Google handles that visit under its own privacy policy.

## Cookies and tracking

The extension does not create, read, or use cookies. It contains no advertising,
analytics, tracking pixels, or user accounts.

## Changes

If the extension's data practices change, this policy and the extension's
Mozilla data-collection declaration will be updated before the new behavior is
released.
